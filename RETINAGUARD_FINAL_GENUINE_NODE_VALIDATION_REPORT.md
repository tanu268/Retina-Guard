## 13. Remaining Numerical Differences
The remaining differences (36 grade mismatches, max probability delta ~0.57) are strictly attributable to **WASM OpenCV vs Native C++ OpenCV GaussianBlur floating-point accumulation order**. Since `cv.GaussianBlur` is executed with a massive 101x101 kernel on WASM float32 arrays, single-precision accumulation differences perturb the output by ±1 pixel value compared to Python's C++ bindings. This is an unavoidable hardware/runtime constraint of the OpenCV.js WASM compilation and not a mathematical logic error in the JS implementation.
